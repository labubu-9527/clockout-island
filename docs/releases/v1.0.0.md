## 分发与更新

安装器和便携可执行文件使用 Clockout-island 产品名，版本为1.0.0。Windows安装器显示发布者 labubu-9527；内部应用ID和已有数据键保持兼容，以继续读取旧数据。未使用原作者交流群或收款码。

本次交付为x64 NSIS `.exe`安装包，含GPL许可页和安装目录下的`licenses/`文件（原项目GPL、第三方声明、岛仔与字体许可）。内部可执行文件名`fly-island.exe`及兼容发行者路径`focusd`保留；安装列表显示发布者为labubu-9527。额外MSI/WiX首次下载工具链受阻，改为使用现有NSIS工具链生成安装器，未声称MSI产物已生成。

本地安装包不含自动更新签名：基础配置公钥为空，应用内更新保持不可用，不会从原作者通道安装更新。后续由维护者配置自己的签名密钥、公钥与GitHub Release清单后再提供自动更新；本次不创建或上传Release，不生成虚假的签名清单。手动下载入口指向维护者仓库。
