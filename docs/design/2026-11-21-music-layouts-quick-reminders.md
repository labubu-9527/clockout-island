用户同意优先借鉴 DotIsle 的音乐布局切换和一句话提醒。本轮按两项独立功能实施，保留已有工作区修改；不增加自由布局编辑器或蓝牙电量功能。

## 音乐布局

- [x] 参考 d09a751 的 music_layout.rs，提供 SideBySide、Separated、LyricFocus、LyricRight、Immersive 五种预设，默认并排，旧存档兼容。
- [x] 在音乐设置中选择并持久化；歌曲/歌词/控制复用现有组件，布局切换保留进度、译文与真实控制能力。隐藏封面仅限沉浸预设。
- [x] 保留68px封面，分离预设56px；居中与沉浸歌词按预设对齐。较高预设增加16px展开空间，沿用230ms平滑过渡与减少动态效果规则。
- [x] 覆盖五布局、无歌词、窄宽、大字号、空闲/暂停及切页，更新音乐设计与设置契约。

## 一句话提醒

- [x] 移植 quick_reminder.rs 的明确语法，支持N分钟后、N小时后、今天/明天H:mm、YYYY-MM-DD H:mm；英文提供等价写法。上限7天相对时间，非法日期/过去时刻/缺标题明确提示，普通任务不误识别。
- [x] 现有待办输入增加解析预览，确认后创建带提醒时间的待办/计划待办；复用既有存储key，增加可选时间和已提醒标记，旧数据不变。
- [x] 到点进入今日待办并触发现有提醒展示；重启补提醒，已完成/已提醒不重复，游戏静默和托盘隐藏规则保持有效。列表显示提醒时刻，支持删除后取消。
- [x] 覆盖跨月跨年、日历/DST、无效输入、时钟推进、重启、日切与普通输入流程；同步待办文档和数据契约。

## 集成与验证

- [x] 两单元实施与独立复核，不覆盖index.html、tray.rs已有修改。
- [x] pnpm check、pnpm build、完整pnpm test:regression；本轮仅前端，若实际触及原生能力则补Rust验证。
- [x] 按功能单元创建本地提交，Obsidian更新原记录和当日日志；未发布、不生成安装包。

`pnpm check` 通过（550项单测、生产与回归类型、lint、行数），`pnpm build`通过，完整`pnpm test:regression`72/72页面通过。音乐页补充五种无歌词/无封面/暂停/无时间线状态后单独重跑196项通过；减少动态效果音乐页188项通过。五布局浏览器mock截图已核查，原生真实播放器仍需用户验收。
