## 音乐模块自定义（2026-11-21）

设置 → 音乐增加「启用自定义排列」，默认关闭，关闭后恢复当前选择的预设。参考 DotIsle `lyric-core/src/custom_layout.rs`（d09a751），六组为歌曲信息、当前歌词、译文与下一句、播放状态、播放进度、播放控制；歌曲信息与控制必须保留，其余可隐藏，封面单独开关。支持拖动、上下按钮与方向键排序；恢复默认不改变预设及启用状态。

自定义采用56px封面、8px模块间距，并跟随字号计算高度；无歌词或无时长时不保留对应模块空位。内容最小134px，与现有86px导航及边距合计220px，匹配原生窗口下限。音量弹层按上下可用空间选择方向，精简布局仍保持滑块在裁剪区域内。复用原有歌词、偏移和真实播放器控制；隐藏译文模块时译文按钮说明原因。设置字段纳入外观预设。

## 五种音乐布局（2026-11-21）

设置 → 音乐 → 音乐面板布局提供封面并排、上下分离、歌词居中、封面右置、沉浸歌词。默认并排，旧存档不改变布局。参考 DotIsle `lyric-core/src/music_layout.rs`（d09a751）：68px封面，分离预设56px，沉浸预设隐藏封面；标题、歌词、进度和控制按同一预设坐标排布，适配本项目20px内容边距和顶部导航。其余四预设增加16px展开空间，大字号继续增加文字空间。右置保留左侧歌词，歌词居中预设居中显示，沉浸歌词突出24px主句。

切换预设保持同一播放器、歌词叶子和译文开关，不重置播放状态或伪造控制能力。位置和封面变化沿用230ms平滑过渡，减少动态效果由全局规则停止过渡。长歌手名给播放状态预留空间，无歌词显示真实曲目信息；空闲继续显示原有空态。布局字段参与外观预设与设置搜索。

## DotIsle 音乐布局（2026-11-20）

双行歌词裁剪修正：音乐态下复用的 `.island__summary` 视口跟随收起条高度，覆盖普通消息的28px固定高度。歌词两行保持原字号/行距并垂直居中，不通过缩小字体或全局取消裁剪规避；消息提醒沿用原视口与过渡规则。100%/120%/150%字号回归检查两行都在裁剪区域内。

后续源码核对：`surface.rs::Surface::paint` 的端点规则移植至 `referenceMusicSurface.ts`。收起底板保持中性，展开时取封面HCT背景；玻璃收起/展开alpha分别196/255、224/255，顶部混入8%的`#dfefff`，边线24/255；经典无磨砂亮面，磨砂亮面15/255，展开玻璃亮面4/255。继续叠乘用户透明度，真实桌面玻璃捕获链路保留。展开封面半径为岛体圆角的一半、上限为封面半高。音乐波形开关表示允许显示，仅正在播放时出现，暂停/停止/无会话隐藏并释放宽度。

源码移植校准（同日后续反馈）：收起音乐胶囊采用DotIsle的`island_layout.rs`、`compact.rs`、`renderer.rs::compact_music`与`surface.rs`，24px封面/6px圆角、三根2px音柱（10/14/8px）、主字体14px/500，副行字体为主字号×0.78并限制9–11.5px，行距1.448、两行间隔1px。副行优先非重复译文，中文回退下一句，其他情况不强制填满。文字测量加76px边距，140–420px范围内自动宽度，增长确认80ms、收缩确认300ms；原有岛仔、通知与倒计时额外计入空间。音乐显示期间渲染为半高圆角胶囊，CSS与原生使用同一几何；退出音乐恢复原设置，重置位置不会把临时形状写进存档。

底板移植`#1b1f25 → #0c0f14`深色渐变、磨砂反射及玻璃196/255透明度，保留用户材质类型。取色改为官方Material Color Utilities的Celebi128色量化、Score筛选、HCT色调24背景/80强调色（对比不足时每次提升2），白/灰/无封面使用中性回退；文字与光效使用对应Content动态角色。192px封面只在变化时处理并缓存8项，替代平均RGB/HSL近似。展开布局保留本项目页面导航与真实播放器能力，不能宣称Vello与WebView2逐像素完全一致。

左侧68px圆角封面及播放状态，右侧曲名、歌手、当前与下一句歌词；中间整行进度与时间，底部居中为上一首、封面取色的圆角播放/暂停及下一首。次要工具为播放模式、收藏、音量、译文和设置。模式及音量调用真实已有命令，当前播放器不支持的模式禁用，收藏明确禁用并说明，不伪造成功。音量拖动与模式请求独立，写入中保留最后一次拖动值。译文仅在已有译文时可切换。

同日对照图校准：有无歌词均使用68px封面，歌名17px、歌手11px；基础岛高276px（包含本项目导航），大字号按比例增加空间，命令错误额外24px。工具按钮间隔6px，主要播放按钮40px；强调色与普通文字混合，降低封面高饱和色带来的刺眼感。封面阴影降低至播放0.28、暂停0.18，大小和圆角使用230ms过渡。以下11月10日布局仅保留历史背景，尺寸与歌词对齐以本节为准。

封面氛围覆盖整个音乐内容区，使用纵向渐隐遮罩（取代下方历史约定的椭圆遮罩），低对比并随主题与暂停状态调整。岛体材质和外沿光效仍由岛壳统一负责。

## 封面氛围（2026-11-20）

音乐内容区新增低对比的封面氛围，仍直接绘制在岛上，不增加嵌套卡片、描边或不透明底色。仅有曲目且有封面时挂载装饰层，离开音乐页随播放器卸载；没有封面与空闲页不留背景占位。复用同一封面图片，不请求额外图片。

氛围由低饱和模糊封面与椭圆渐隐遮罩组成，限制在内容区内，浅色主题进一步降低不透明度。全局经典、液态玻璃、磨砂玻璃材质仍由岛壳负责。氛围层 `aria-hidden` 且不接收指针事件，低于歌曲、歌词、进度与操作控件；没有新增持续动画，暂停时颜色更淡，减少动态效果时关闭氛围过渡。

保留歌曲→歌词→进度→播放控制的层级，歌词仍是文字焦点，播放/暂停仍是主操作。保留现有诊断入口、兼容性浮层、时间线与校准规则、逐字填充默认关闭，以及全部真实空状态和控制错误含义。专用回归页 `music-surface.html` 覆盖浅深主题、90%/120%字号、85%/120%缩放、长标题、歌词有无、暂停、错误、无封面及未知时间线。

- 逐字填充默认关闭；开启后有逐字时间的歌词以当前高亮色逐步点亮，其余文字降低不透明度，折叠和展开态一致。（用户要求 2026-11-15）

全局方向见 [DESIGN.md](../../DESIGN.md)。

- 无时间线时进度条降低透明度并说明“估算”，保持不可拖动；歌词行可通过键盘或点击校准本地秒表，有时间线且允许跳转时点歌词直接跳转。兼容性提示是浮在歌词区上的小卡片（不透明岛屿底色、阴影），不参与播放器排版，封面和歌词保持原来的大小（用户反馈 2026-11-12：上一版把卡片塞进排版、压缩封面，封面像是没了）。同一播放器的同一问题只自动弹出一次，收起后头部右上保留一个强调色的提示图标，点它再打开；设置 → 音乐列出全部检测结果。（2026-11-12 用户要求）

## 正在播放（2026-11-10 重做）

用户觉得上一版（左封面、右侧一栏、歌词垫在波形上的深色卡片）不好看。这一版从头设计，参照 Apple 灵动岛 / 正在播放、Spotify 迷你播放器和 Windows 11 媒体浮窗。（Agent 推断）

- **不再是一张卡片**：音乐页像 Agent 页一样直接画在岛上，没有卡片底色和描边，岛本身就是播放器。层级只靠字号、字重和留白。
- **结构（从上到下）**：歌曲（封面 + 歌名 + 歌手）→ 歌词（有歌词时）→ 进度条 → 播放控制。页面高度不变（岛 320px）。
- **没有歌词时**：封面 112px，歌名 20px / 600、最多两行（长名省略），歌手 14px，下面一行灰色的"专辑 · 播放器"；中文歌只查了 LRCLIB 没找到时，这一行换成强调色文字链接"没找到歌词 · 试试酷狗和网易云"（点开设置 → 音乐）。
- **有歌词时**：封面缩到 52px，歌名和歌手各一行（15 / 13px），把位置让给歌词；封面大小和圆角在 360ms 内过渡。歌词三行、居中（2026-11-10 用户反馈：靠左时整页明显不对称），和进度条、播放控制在同一条中线上，左右各留 60px 给快慢控件：当前句 18px / 600 最亮，上一句和下一句 13px 灰色，上下边缘再淡出一些；换句时新句从下一句的位置上移 8px 淡入。逐字歌词照旧逐字点亮；有翻译时翻译代替下一句。这首歌的快慢（− 0s +）只在鼠标移到歌词上或用键盘进入时出现在歌词右上角。
- **封面**：圆角 16px（小封面 12px），柔和方圆；下面垫一层模糊放大的封面当阴影，带出这首歌的颜色（播放时 .55，暂停时 .3）。2026-11-20 新增的低对比内容区氛围与该阴影叠加，仍不取代岛壳材质。暂停时封面缩到 94%，播放时回到 100%（同 Apple Music）。没有封面时是深色渐变方块和音符。
- **强调色**：从封面取平均色（饱和的像素权重更高），调到在黑底上读得清的亮度（`features/media/artworkTint.ts`），用于右上角的跳动小条和歌词提示链接；没有封面时是柔白。进度条不再跟封面变色（2026-11-11 用户反馈：绿色进度条很怪），用岛上普通的前景灰白 `--text-2`，和播放控制一致。
- **右上角**：四根跳动的小条（纯 CSS，播放时跳、暂停时落下，减少动画时静止），旁边是麦克风图标按钮"歌词设置"，打开设置 → 音乐。不用齿轮，因为岛的顶栏已经有设置齿轮。
- **进度条**：整行宽、4px；下面左边是已播放时间，右边是剩余时间（"−3:26"），等宽数字。播放器不报告时长（如网易云）时，用歌词来源（LRCLIB、酷狗、网易云的搜索结果）给的歌曲时长；位置照旧由岛自己从看到这首歌起计时。两边都不知道时长时才不显示。（用户要求 2026-11-10：网易云下也要有进度条）缓存里没有时长的旧歌词会重新查一次。
  - **拖动跳转**（用户要求 2026-11-11）：播放器允许外部跳转（媒体会话的 `IsPlaybackPositionEnabled`）并且自己报告时长时，进度条可以点、可以拖。指向时条变粗到 6px、填充变亮、末端出现 10px 的白色圆点，光标变手形；拖动时时间和填充直接跟着指针走（不带过渡），松手才发一次跳转（`media_seek` → `TryChangePlaybackPositionAsync`），岛上马上显示新位置，不等播放器回报。键盘：方向键前后 5 秒，Home / End 到头尾。点击区上下各多 6px，不占布局。
  - 播放器不让跳转、或时长是借歌词来源的（网易云不装插件）时，进度条保持只读：没有手形光标、不变粗、没有圆点。
- **播放位置怎么算**（用户反馈 2026-11-11：在播放器里拖了进度，岛上的歌词还照旧往下走）：
  - 媒体会话的时间线是一份"快照"：`Position` 是 `LastUpdatedTime` 那一刻的位置，播放器想推才推（Spotify、浏览器每次跳转 / 暂停 / 继续都推，有的只在换歌时推一次）。所以位置 = 快照位置 + 从 `LastUpdatedTime` 起过去的时间 × 播放速度，而不是从岛读到它时算起（`media_control/timeline.rs`）。
  - 没有新快照时，暂停就停在暂停那一刻推算出的位置，继续播放从那里接着走，不会把暂停的时长也算进去；时间戳缺失、是 0、在未来、或比整首歌还旧时，当作"现在"取的；位置变了但时间戳没变的播放器，也当作现在取的。从岛上跳转后，播放器不推新快照也按跳转的位置走。
  - 后台线程订阅每个会话的 `TimelinePropertiesChanged`、`PlaybackInfoChanged`、`MediaPropertiesChanged`（以及会话增减），一有变化就发 `media-session-changed`，岛立即重读，播放器里一拖，歌词马上跳过去；1.5 秒的轮询照旧兜底（有的播放器不发事件）。音乐关掉、岛不再读状态 10 秒后线程自己退出。
  - 前端只在新读数和岛自己推算的位置差 300ms 以上（跳转、暂停、校正）或换歌、换播放状态时才重新定锚（`features/media/positionAnchor.ts`），否则保留原来的锚点：不再每次轮询都让整页重渲染、让逐字歌词重启。差 1.5 秒以上算跳变，进度条填充直接跳过去，不滑过去。
  - 已知做不到的：**网易云音乐**自带的 SMTC 不给时间线（位置和时长都是 0），岛只能自己从看到这首歌起计时，在网易云里拖进度岛上不会跟；装 InfLink-rs 插件后有完整时间线。**酷狗**、AIMP、foobar2000（不装插件）同样没有时间线；旧版 **QQ 音乐**（21.10.2962 之前）也没有。这些情况下不假装知道位置。
- **播放控制**：三个不带底色的白色图标，播放 / 暂停更大（26px，48px 点击区），上一首、下一首 22px，间距 28px；悬停时出现浅色圆底，按下缩到 90%。不能切歌时按钮变淡。
- **没有在播放**（2026-11-10 重做，用户在真实应用里看过：原来的样子丑）：不再是"一个空播放器"——没有空封面、进度条和变灰的上一首 / 播放 / 下一首。页面中间一组：左边一张静止的黑胶唱片（92px，细纹、深色圆标、淡淡一道反光，纯 CSS，不转），右边"没有在播放"、一句"在任意播放器里放一首歌，就会出现在这里"，和一个安静的胶囊按钮"▶ 继续播放"（发送系统播放键，让上次用的播放器接着放；指向时提示这一点）。只用灰色：颜色留给歌曲封面。实现在 `MusicIdle.tsx`；检查页 `tests/regression/music-lyrics.html?view=idle`。
- 去掉了波形（`MediaWaveform`）：它和歌词抢位置，也是上一版显得杂乱的主要原因。收起岛上的音乐小条（`MusicWaveButton`）保留，颜色从薄荷绿改为普通前景灰白（`--text-2`，指向时 `--text-1`），播放时不再发绿光（2026-11-11 用户要求）。
- 回归页 `tests/regression/music-lyrics.html` 检查以上各状态；`island-tour.html?media=playing|paused|nocover|long|nolyrics|none`（`&lyrics=0` 关闭在线歌词）可以在整个岛里看。
- **设置 → 音乐 → 播放器顺序**下方一直有一行提示"不显示封面？请在播放器的设置里打开 SMTC（系统媒体控制）"：封面来自 Windows 媒体会话，播放器不开 SMTC 就不交出封面。（用户要求 2026-11-11）这行提示做成一条轻量的信息框（2026-11-11 用户反馈：不够显眼）：左边 info 图标，文字比普通说明亮一档（`--color-text-muted`），极淡的底色和细边框，不用强调色。
- **在线歌词默认打开**：设置 → 音乐里的"在线查找歌词"和其下的"酷狗和网易云"新装默认都开（用户要求 2026-11-10）；已经保存过关闭的照旧关闭。
- 网易云缺少时间线时，提示卡里是强调色胶囊按钮“一键启用”和同一行的“了解详情”，下面一行灰色说明；结果写在按钮下方，并直接给出下一步（“关闭网易云并继续”“立即重启网易云”），不显示英文原始报错。设置中的那一行与其他设置行同样排版：右侧是强调色文字按钮（一键启用 / 卸载，卸载需二次确认），状态和结果写在标题下，许可说明放在分组底部。
