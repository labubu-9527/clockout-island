用户已明确要求三项都实现。参考 DotIsle d09a751 的 `gestures.rs`、`wireless_battery.rs` 和 `custom_layout.rs`。分三个可独立验证单元实施，原有index.html、tray.rs与未跟踪文件保留；不推送、不打包安装器。

执行顺序：独立功能先定向验证，三项集成后跑全套。本阶段共用壳层、设置搜索与契约文档，验证后创建一个完整提交，避免中间提交缺少配套字段。

## 一：上推隐藏

- [x] 先测试纯手势状态机：向上8px且纵向超过横向1.25倍锁轴；40px或有效快速上推、抵达屏幕上沿时提交；短拖与反向拖动取消，位移使用72px阻尼曲线。
- [x] `useWindowDragGesture`接入手势分流，复用已有贴边隐藏与恢复，不写临时位置；屏幕坐标按实际DPI换算。普通方向仍调用原生移动；按钮、输入、文字选中区不接管，捕获取消与失焦清理。
- [x] 通用设置增加默认关闭的`swipeUpToHide`，缺失旧值为false，位置锁定仍允许手势隐藏而不允许移动。提供中英文文案。
- [x] 验证实际指针流程、误点击屏蔽、禁用恢复及贴边行为；随本阶段集成验证后提交。

## 二：无线设备电量

- [x] Rust单独模块提供`get_wireless_devices`，返回设备id、名称、种类、可缺省百分比与更新时间，类型化前端API同步。只读取当前已连接经典蓝牙/BLE端点，按物理设备去重；PnP电量优先，BLE标准Battery Service兜底，未知不伪造。
- [x] unsafe集中在win32，无生产unwrap/expect。扫描独立有界工作线程，防并发重复扫描，单操作与完整扫描均有超时、缓存和错误返回；停用/关闭面板不持续启动扫描。
- [x] 设置页提供默认关闭的独立无线电量模块、刷新、真实错误/空态与设备列表；岛上提供可开关的紧凑入口与查看面板，低电量提示接入既有提醒队列且去重。新偏好单独storage安全读写，不收集MAC到问题记录。
- [x] 测试去重、未知电量、超时、防重入、禁用与失效快照；前端全套加cargo test和tauri无安装包构建，随本阶段集成验证后提交。

## 三：音乐自由布局编辑器

- [x] 扩展现有musicCustomLayout v1，以可选元素坐标保存400逻辑像素设计空间；旧配置无坐标仍按六模块堆叠。仅有效有限坐标、去重、边界约束；隐藏模块不会因保存坐标重新出现。
- [x] 设置→音乐提供编辑画布，展示实际布局预览。歌曲信息、封面、主/副歌词、状态、进度、真实控制支持选择和拖动；可伸缩文本/进度通过宽度控件调整，方向键微调，数值输入与重置提供非鼠标途径。
- [x] 播放器按同一几何渲染实际点击目标，宽度按400设计空间比例换算，高度包住最底元素并遵守220px原生下限；工具栏弹层仍在裁剪范围内，保留原播放器能力与预设切换。编辑器不调用真实媒体控制。
- [x] 纯几何测试覆盖非法值、缩放、隐藏、恢复；浏览器测试覆盖拖动/键盘、持久化、真实播放器命中与放大字号；随本阶段集成验证后提交。

## 最终结果

三项功能已落地，独立规格/质量复核完成。补修了短拖回弹、蓝牙部分枚举失败误报空列表、未开始枚举时的超时、多设备低电量等待过期，以及新增槽位导致默认排列恢复按钮状态错误。相应用例先失败后通过。设置搜索覆盖三项新入口，列表可滚动但不显示滚动条，原有index.html与tray.rs改动保持未提交。

`pnpm check`通过566项单测及类型/lint/行数；`pnpm tauri build --no-bundle`包含前端构建并成功生成release可执行文件，未生成安装包；完整`pnpm test:regression`为77/77页通过；减少动态效果的手势/画布/播放器3页通过（播放器211项）。`cargo test --manifest-path src-tauri/Cargo.toml -j 2`为499项通过、14项按既有规则忽略；`cargo clippy --all-targets`成功，仅剩存量`win32/system_status.rs`的field_reassign_with_default提示。前端及web-demo构建仍有现有体积提示。

桌面Clockout-island快捷方式已同步到新release；运行中的旧debug实例未替换。画布截图完成浏览器视觉核查，不等同Windows实机验收。真实蓝牙驱动/电量准确性、多屏混合DPI与系统媒体控制仍待实际验收；不推送、不打包安装器。

## 后续校准：缩放拖动与投递提交边界

85%界面缩放时，鼠标移动20px而画布元素只移动约17px。修复为按画布实际显示宽高分别换算横向设计坐标与纵向逻辑坐标；覆盖320/520宽度与85%/100%/120%缩放的六组回归，修复前失败、修复后通过，存档格式不变。

提醒回归暴露了异步提交边界：投递成功后、React尚未提交reminded时，第二次轮询可以再次响铃和开页。确定性回归同一提交前驱动两次轮询，修复前得到2次投递。现增加短期已投递ID，在状态提交后清理；投递拒绝不占用ID，可正常重试。没有改变持久化标记、静默或托盘隐藏规则。最终`pnpm check`通过566项单测及全部静态检查，78/78页完整回归通过，新增用例补强拒绝回调计数后单独重跑通过；`pnpm tauri build --no-bundle`成功生成包含两处修复的release文件。本轮未改Rust，不重复运行Rust测试；上阶段原生验证记录保留。
