用户已确认：按截图做紧凑天气卡，左侧图标/温度，右侧体感/湿度/风速/日出日落，七日高低温曲线与小时预报切换。自动/手动位置模式，自动按网络出口定位缓存3小时，手动刷新重新定位，失败保留上次结果并允许选择城市，旧手动城市保留。主体/间隙/侧栏统一悬停保持，间隙仍点击穿透。不得提交代码，不生成安装包。

1. 原生悬停修复：拆分点击命中与悬停保持。展开且有消息栏时连接主体与栏的矩形走廊，仅覆盖消息栏实际高度及必要角部；不扩大点击区域。游戏穿透/贴边/无侧栏保持原规则。测试跨DPI/缩放、gap点击穿透但hover保持、离开后关闭。
2. 原生天气：新增固定HTTPS来源自动定位命令，优先两家直连再系统代理回退，校验/超时/响应限额，不记录IP与坐标。返回WeatherCity，坐标适用两提供商。扩充预报DTO可选日出/日落，Open-Meteo和和风实际解析，同步API测试。
3. 前端天气：位置模式及3小时缓存，旧有城市迁移manual，无城市默认auto；位置失败保留旧结果但标注状态，不能覆盖手选城市。请求防重入/过期请求守卫，手动刷新重定位。设置页和岛内设置位置控制一致。天气卡适配深浅/玻璃，七日曲线和小时切换，可访问双语，缺日照显示--。天气图标按现有Lucide体系着色。
4. 验证：针对性红绿测试；pnpm check/build/test:regression/build:web-demo；cargo test；tauri build --no-bundle；交叉审查修正并归档Obsidian，不提交。
