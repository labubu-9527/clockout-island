## 约束

保持现有消息优先级和系统状态 CPU/MEM 契约；只读硬件状态，不注册或拦截快捷键。保留工作区已有未跟踪文件。不生成安装包。新增文案中英双语，单文件遵守仓库行数限制。

## 实施步骤

- [x] 为 `features/device-notices/model.ts` 添加差分、未知恢复、关闭过滤和两秒过期测试，先确认失败，再实现纯逻辑。
- [x] 创建 `win32/device_status.rs` 和 `system/device_status.rs`，复用 COM 音频安全封装；注册 `get_device_status`、`set_device_notices_enabled`。主消息线程维护始终传递输入的只读全局锁定键观察器，仅统计下游未拦截的事件；阻塞线程读取音频/触控板，返回可未知的状态，不修改系统设置。
- [x] 创建该 feature 的 `api.ts`、`storage.ts`、轮询 hook、提醒组件和设置组件；快照轮询防重入，失败重建基线，关闭取消采样，存储兼容损坏与缺失值。监听启停串行化，跨阻塞边界的响应丢弃，解除阻塞先建立基线。
- [x] 在 `AppearanceSettingsPage.tsx` 增加四项开关；在 `IslandApp.tsx`、`IslandShell.tsx`、`IslandCollapsedBar.tsx` 接入临时内容及尺寸，复用贴边露出和悬停保持。
- [x] 添加浏览器回归页，覆盖计时、开关、优先级、语言、宽度和玻璃材质，37 项定向检查通过。同步 `contracts.md`、`data-storage.md` 和岛屿设计文档。
- [x] 执行前端总检查及构建、完整浏览器回归、Rust 测试和无安装包 release 构建；完成代码复审并修正两项边界问题。前端 503 项、Rust 492 项通过；新增设备提醒 37 项通过。全量 66 页中 64 页通过，两项设置页因新增分组/四行开关的旧预期失败，更新夹具后普通/功能开启模式各 249 项及同筛选的四个插件设置页全部补验通过，不描述为一次完整全绿。实现按完整功能单元提交，问题结果归档到个人知识库。

原生全局键盘监听另通过显式运行的桌面测试，验证切换、关闭重启监听及恢复原锁定状态；运行结束还原键盘状态。只观察未被下游键盘工具拦截的按键，不吞键或注册快捷键。真实物理键盘、睡眠/安全桌面、各品牌触控板和实际麦克风兼容性仍待用户验收。
