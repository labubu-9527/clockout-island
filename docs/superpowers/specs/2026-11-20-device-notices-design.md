# 系统状态短暂提醒

| 项目 | 内容 |
| --- | --- |
| 文档名称 | 系统状态短暂提醒设计 |
| 制作人 | XiaoZhu |
| 日期 | 2026-11-20 |
| 版本号 | v1.0.0 |

用户已确认：Caps Lock、Num Lock、默认麦克风静音与受支持的触控板开关变化，在岛上展示图标、名称和状态约两秒；四项独立开关集中放在外观设置，外观继承当前岛体材质。

首次读取、恢复读取和重新启用只建立基线，不弹启动提醒。只在已知布尔状态发生变化时提醒；读取失败为未知，不能解释为关闭。连续变化替换当前提醒并重置两秒，不积压旧状态。功能关闭或卸载取消轮询与定时器。

收起态临时替换普通内容，提醒不依赖文字开关，结束恢复歌词、指标和岛仔原布局。临时尺寸与原生命中区域一致，兼顾手动窄岛和字号缩放。展开页面、游戏免打扰、消息预览和额度提醒期间丢弃系统提醒，并继续更新基线，避免稍后补弹旧状态。贴边时通过现有消息露出机制短暂显示，结束按原规则回缩。

Windows 原生只读采样：键盘在主消息线程使用只观察的全局低级键盘监听，始终传递输入，不拦截按键、不注册快捷键；长按只切换一次。麦克风查询默认输入端点的系统静音状态，不录音、不改静音；触控板仅支持可检测的 Windows 精确式触控板开关，不写注册表、不修改驱动或设备状态。不支持或未知状态不产生通知。触控板本次运行至少检测到一次硬件后才能继续跟踪关闭变化；启动时已关闭且不参与枚举的设备可能保持未知。

新增领域 `features/device-notices/` 保存四项偏好、状态差分和短暂提示组件；窗口层负责与消息优先级、尺寸和悬停组合。Rust `system/device_status.rs` 提供类型化只读快照命令，Windows API 限定于 `win32/`。不改变现有 CPU/内存快照格式。

验证覆盖状态差分、初始/未知/恢复/开关过滤、两秒到期及连续变化、窄岛字号、两种语言、材质继承、消息优先及展开抑制。完成前运行前端总检查、构建、完整浏览器回归、Rust 测试和无安装包 release 构建。真实硬件和客户端内部静音兼容性单列人工验收。
